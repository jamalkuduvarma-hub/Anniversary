## GitHub Pages

1. Upload/replace all three website files in your GitHub Pages repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Commit/push the files.
4. Open your GitHub Pages URL.

## Important security note

This is a client-side privacy gate because GitHub Pages is a static hosting service. It is suitable for keeping the page away from casual visitors, but it is NOT equivalent to server-side authentication. The password is present in the JavaScript source, so someone with technical access to the site files could discover it.

The original story content and design have otherwise been preserved.
